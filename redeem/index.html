Account overview

Need help redeeming a code?
  • What a code looks like. Five groups of five letters and numbers. Capitals, dashes and spaces do not matter; paste it exactly as it came.
  • Each code works once. If it says the code is not valid, check it for typos. A code somebody already used reads the same as a wrong one.
  • It goes to your IDUNA account. If you have played DEADWEIGHT as a guest on this device, open the game and choose “Save progress with IDUNA” first, so the code lands on the account you actually play.
  • Founder codes give permanent Founder status in DEADWEIGHT and lift your Draft tickets to 9,999, which is effectively unlimited. Reload DEADWEIGHT, or just switch back to its tab, and the new balance shows.
